# CONVENTIONS.md — Doctrina

Aider reads this file as read-only context once wired in: launch
with `aider --read CONVENTIONS.md`, or add `read: CONVENTIONS.md`
to `.aider.conf.yml` so it loads on every run. This project routes
all operational rules through the open AGENTS.md standard.

See `AGENTS.md` for the canonical operational source of
truth. The Doctrina framework artifacts (specs, decisions,
changes) live under `.doctrina/`.

Read order is documented in AGENTS.md.
